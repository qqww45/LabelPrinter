# 签立方站点信息架构与体验改版设计

日期：2026-11-03  
仓库：qqww45/LabelPrinter  
站点：https://ci64.com/  
状态：已与产品方确认，待写实施计划

## 背景与问题

当前打开站点即进入编辑器；`WelcomeGate` 全屏欢迎只出现一次，之后无法回访；模板库是弹窗；没有可收藏的帮助页。竞品有可反复进入的首页引导、模板浏览与帮助，体验更完整。

## 目标

1. 完整营销首页，引导客户理解产品并进入正确路径。  
2. 模板库升级为独立单页，并扩充一批行业/尺寸模板。  
3. 帮助页为与现有功能一一对应的完整手册。  
4. 首页 / 模板 / 帮助 / 工作台均有可收藏 URL。  
5. 不堆未实现功能；导航与文案只映射已上线、可用的能力。

## 非目标（本轮不做）

- 账号体系、云端同步、多端登录  
- Docker / 自部署路径（坚持边缘部署）  
- 未实现能力的营销话术或空壳模板  
- 拆成独立营销站与编辑器双部署（见方案取舍）

## 已确认决策

| 议题 | 决定 |
|------|------|
| 默认落点 | 本地已有项目 → `/app`；无项目 → `/`。收藏的深链始终按 URL 打开，不被默认落点覆盖 |
| 方案 | A：轻路由壳 + 四大页面（Vue Router） |
| 首页深度 | 对标竞品的完整营销落地页 |
| 模板库 | 单页改造 + 本轮扩充一批行业/尺寸模板 |
| 帮助 | 完整手册，章节与现有功能一一对应 |
| 欢迎遮罩 | 去掉一次性 `WelcomeGate`；首次引导并入首页 CTA + `/app` 空画布轻量 onboarding |

## 信息架构与路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 营销首页 | 完整落地页 |
| `/templates` | 模板库 | 可带 `?scene=` / `?size=` / `?pick=1` |
| `/help` | 帮助手册 | 锚点如 `/help#字段映射` |
| `/app` | 编辑器工作台 | 现有 App 能力迁入 |

部署：EdgeOne（或等价静态托管）配置 SPA fallback，深链刷新不 404。

### 顶栏（`/`、`/templates`、`/help` 共用）

签立方 | 首页 | 模板库 | 帮助 | 「打开工作台」→ `/app`

### 编辑器内导航

保留原工具栏；增加通往首页 / 模板 / 帮助的入口。模板主入口改为 `/templates`（可保留「快速套用」捷径）。

### 默认落点算法

1. 若 URL 已是 `/`、`/templates`、`/help`、`/app`（含 query/hash）→ 尊重 URL。  
2. 否则（访问站点根且无深链偏好时）：`localStorage` / IndexedDB 中有可恢复项目 → 跳转 `/app`；否则 → `/`。

## 营销首页 `/`

自上而下：

1. **顶栏**（同上）  
2. **Hero**：价值主张（表格一行 → 可贴标签）；主 CTA「从模板开始」→ `/templates`；次 CTA「打开工作台」→ `/app`；副链「使用帮助」→ `/help`  
3. **三步流程**：选模板 → 导入表格 → 打印或导出（示意，不堆功能名）  
4. **场景入口**：生鲜价签、快递面单、资产贴 → `/templates?scene=…`（或约定带场景进 `/app` 的等价深链）  
5. **能力条**：仅列已有能力——本地数据、字段映射、表达式、按列份数、图片字段、流水号、打印前体检、PDF/热敏指令；每项链 `/help#对应章节`  
6. **信任**：开源、数据留在本机浏览器、边缘部署免安装  
7. **页脚**：备案、GitHub、帮助/模板链接  

去掉全屏一次性 `WelcomeGate`。

## 模板库 `/templates`

### 布局

- 顶栏同首页  
- 筛选：行业场景、标签尺寸、用途（价签 / 面单 / 资产 / 仓库…）  
- 主区卡片网格：缩略预览、名称、尺寸、场景  
- 详情（侧栏或中部）：大预览、所需字段、「使用此模板」

### 使用模板

进入 `/app`，套用版式 + 示例数据（与现有 scene pack 行为一致）。编辑器内打开模板库走本页；`?pick=1` 表示选完回到工作台。

### URL

- `/templates`  
- `/templates?scene=retail-price`  
- `/templates?size=60x40`  
均可收藏。

### 扩库（本轮）

在生鲜 / 快递 / 资产之上，扩充可打的行业 × 尺寸组合（零售多尺寸价签、仓储条码、珠宝/服装吊牌、物流面单变体等）。每张具备：预览、字段说明、可套用。禁止未实现能力的空壳模板。

## 帮助 `/help`

### 形态

左栏目录 + 右栏正文（移动端目录可收起）。顶栏同首页。章节锚点可收藏。

### 目录（与现有能力一一对应）

1. 快速开始（场景包 / 从模板进工作台）  
2. 项目与本地保存  
3. 导入 Excel/CSV（追加、替换、按主键更新）  
4. 字段映射与记忆  
5. 画布与组件（文本 / 条码 / 二维码 / 表格 / 图片…）  
6. 文本表达式与空则隐藏  
7. 按列份数打印  
8. 图片字段（URL / data）  
9. 流水号  
10. 纸张与排版  
11. 打印设置与热敏（TSPL/ZPL）  
12. 打印前体检  
13. 预览、打印、PDF/图片导出  
14. 打印中心与队列  
15. AI 排版（可选密钥，本地调用）  
16. 常见问题  

每章结构：做什么 → 点哪里 → 示例 → 链到相关界面。属性面板内表达式说明链到对应章节，避免双份文案漂移。

## 功能映射原则

- 首页能力条、帮助目录、模板字段说明必须能指回真实 UI 与行为。  
- 新增对外文案前先核验：代码路径存在、可操作、可验证。  
- P0 已合入能力（表达式、份数列、图片 URL、流水号等）必须有帮助章节与首页入口链。

## 技术约束

- 栈：现有 Vue 3 + Vite；引入 `vue-router`（方案 A）。  
- 数据与项目仍仅存浏览器本地；营销/帮助页不引入账号。  
- 部署：仅边缘静态（EdgeOne / ci64.com），配置 history fallback。  
- i18n：沿用现有 `t()`；新文案进同一套词条。

## 成功标准

1. 无项目访问站点根看到完整首页；有项目默认进 `/app`；直接打开 `/help` 等深链不被重定向掉。  
2. `/templates` 可筛选、预览、套用；扩库模板均可套用出预览。  
3. `/help` 十六章可锚点访问；从首页能力条可跳到对应章。  
4. 刷新深链不 404。  
5. 去掉 WelcomeGate 后，首次用户仍能从首页走到「模板 → 工作台」闭环。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 默认跳转 `/app` 让人以为没有首页 | 编辑器与首页顶栏双向可达；页脚/关于保留站点链 |
| 扩库质量不齐 | 每模板强制预览 + 字段列表 + 套用冒烟 |
| 帮助与产品漂移 | 表达式等以单一内容源或明确「帮助为准、面板链过去」 |

## 实施顺序（建议，细节见后续 plan）

1. 接入路由与 SPA fallback，迁出 `/app`  
2. 共用顶栏 + 首页落地  
3. 模板库单页 + 筛选/套用 + 扩库  
4. 帮助手册正文与锚点  
5. 去掉 WelcomeGate，整理 onboarding  
6. 回归：深链、默认落点、模板套用、帮助锚点
