# 签立方营销壳视觉改版设计

日期：2026-11-03  
仓库：qqww45/LabelPrinter  
站点：https://ci64.com/  
状态：已与产品方确认，待用户审阅后写实施计划

## 背景与问题

信息架构改版（PR #5 / #6）已上线：`/`、`/templates`、`/help`、`/app` 可收藏，滚动与矢量模板预览可用。观感仍偏「白底灰卡 + 线框缩略图」：

- 首页 Hero / 场景区几乎没有真实贴物感，难以建立「印出来可贴」的心智。
- 模板库卡片以蓝框矢量预览为主，视觉同质、偏工具草稿，不像产品目录。
- 帮助与页头页脚同属营销壳，版式密度与分区层次偏弱，整体不像 SaaS 落地页。

本轮只升级营销壳视觉与摄影资产，不改路由与功能范围。

## 目标

1. 整站营销壳（首页、模板库、帮助、页头页脚）达到产品官网感：大图分区、清晰层级、轻动效。
2. 尽量使用「标签已贴在真实物体上」的场景摄影（AI 生成），替代营销区里的空白感与纯矢量示意。
3. 保留现有品牌蓝主色；通过版式、留白、摄影与轻动效拉高质感。
4. 工作台 `/app` 交互与布局不变（仅共享顶栏若复用组件时保持导航可用）。

## 非目标

- 账号体系、云端同步、付费墙、多语言新增文案大改
- Docker / 自部署；改边缘部署策略
- 重做编辑器画布、打印引擎、模板数据模型
- 外聘设计师 Figma 流程（本轮由实现方出视觉方案 + AI 图并直接落地）
- 替换全部矢量预览能力：模板选中后的字段细节区仍保留矢量预览

## 视觉系统

### 色与字

- 主色：沿用现有 `--primary` 蓝（约 `#2563eb` 体系），按钮、链接、选中态不变色相。
- 背景：营销页底用浅灰分区（如 `#f8fafc` / 轻微冷灰），卡片与面板纯白；深色主题下对应调暗，摄影图仍可用同一套资产。
- 字号：Hero 标题 `clamp(32px, 5vw, 48px)`；区块标题约 24–28px；正文 16px、次要 13–14px；行高 1.5–1.65。
- 圆角：卡片 16px；按钮与 chip 保持现有习惯；摄影图容器可 12–20px + 轻阴影。

### 版式

- 内容最大宽度约 **1120–1200px**（相对当前 1080 略放宽）。
- 区块纵向间距加大（约 56–80px），避免「一串灰卡贴在一起」。
- 顶栏：轻毛玻璃或半透明白底 + 底部分割线；桌面仍为「签立方 | 首页 | 模板库 | 帮助 | 打开工作台」；窄屏收纳为汉堡菜单（若当前无汉堡则本轮补上，保证三链 + CTA 可达）。
- 页脚：分区清晰（产品链接 / 开源与备案），背景与主内容区分隔。

### 动效

- 区块进入视口时短淡入 + 上移（约 200–400ms）；Hero 摄影可极轻浮动或视差。
- 严格尊重 `prefers-reduced-motion: reduce`：关闭位移动画，可保留瞬时透明度。

### 摄影规范

- 题材：价签贴货架/商品、快递面单贴包裹、资产贴贴设备机柜、库位签贴货架梁、珠宝签/吊牌等与现有场景包一致。
- 风格：统一色温、略浅景深、干净商业摄影；**图上不叠大段营销文案**（文案走 HTML）。
- 禁止：杂乱水印、可读假品牌 Logo 抢戏、血腥/违禁内容、与签立方无关的 UI 假截图冒充产品。
- 格式：优先 WebP（备 PNG），长边按用途约 1200–1600px（Hero）/ 800px（卡片）/ 1600×400 级（帮助章首条带）。
- 落盘：`public/marketing/`，文件名语义化，例如 `hero-shelf-price.webp`、`scene-express-parcel.webp`、`tpl-cover-grocery-price.webp`。

## 页面设计

### 首页 `/`

自上而下：

1. **顶栏**（共用）
2. **Hero**：左文右大图。右图为贴物场景（默认超市价签贴商品/货架），不再用单独矢量 specimen 作为主视觉；可保留极小尺寸标注 chip（如「超市价签 70×40」）。CTA 不变：从模板开始 / 打开工作台 / 使用帮助。
3. **三步上手**：每步一张小场景图 + 原有文案；卡片改为图上文下或左图右文。
4. **常见场景**：六格（或现有 SCENE_PACKS 筛选集）**场景摄影卡片**；点击仍进 `/templates?scene=`。
5. **已有能力**、**为什么放心用**：版式收紧为更像官网的能力条 / 三列信任卡；链到 `/help#…` 与 GitHub 逻辑不变。
6. **页脚**

可选增强（实施时若时间紧可降级）：Hero 下增加一条极窄「打印预览条」装饰，仍用营销图而非编辑器截图。

### 模板库 `/templates`

- 筛选侧栏与搜索保留；栅格卡片 **封面改为贴物场景图**（按 `templateId` 或场景映射；无专用图时回退到同场景默认图，再回退矢量预览）。
- **选中态下方大预览**仍用现有 `TemplatePreviewThumb` / 矢量预览，便于核对字段与尺寸——摄影不替代结构预览。
- 卡片元数据（名称、尺寸、分类）层级加强：封面占比提高，标题加粗，次要信息弱化。
- 空结果 / 加载态与现有行为一致。

### 帮助 `/help`

- 章首或手册顶区增加窄条场景图（通用「工作台旁标签卷/已贴标签」一类，避免每章强行换图造成噪音；若资源够可为 2–3 个大章配不同条带）。
- 目录 + 正文加宽、标题层级与段落间距按官网阅读优化；**锚点、RouterLink、hash 滚动行为保持 PR #6 已修好的逻辑**。
- 不重写帮助正文内容（除非排版必须拆段）；不新增未实现功能说明。

### 页头 / 页脚

- 视觉与营销页统一；页脚「首页」继续指向营销首页（`/?home=1` 或项目已约定的营销强制参数），不得误进工作台。
- Logo 与「打开工作台」主按钮样式微调以适配毛玻璃顶栏，不改跳转。

## 资源与映射

新增模块（名称可微调，职责固定）：

- `public/marketing/*`：静态图。
- `src/content/marketingAssets.js`（或等价）：导出  
  - `HERO_IMAGE`  
  - `STEP_IMAGES[1..3]`  
  - `SCENE_IMAGES[sceneId]`  
  - `TEMPLATE_COVERS[templateId]`（可稀疏）  
  - `HELP_BAND_IMAGE`  
  以及 `alt` 文案（中文，可走现有 `t()`）。
- 组件：例如 `MarketingImage.vue`（统一圆角、懒加载 `loading="lazy"`、缺图占位）。

生成流程（实施阶段）：用图像生成工具按规范出图 → 人工抽检贴物可读性与色温 → 压缩入库 → 映射表接线。允许同一张场景图被多个相近模板封面复用，避免 1:1 强求每模板独图。

## 技术约束

- 仅改营销壳相关 Vue / CSS / `public`；路由表与默认落点算法不改。
- 保持 Edge 静态部署：图片走 `public/`，注意总体包体；大图用 WebP，必要时对 Hero 做适度尺寸限制。
- i18n：新增可见字符串走现有 `t()`；图片 `alt` 同样。
- 深色主题：摄影图本身可不换，容器背景与文字对比度达标。
- 无障碍：装饰性图 `alt=""` 或有意义的短 alt；动效可关。

## 测试与验收

1. `npm test` / `npm run build` 通过。  
2. 人工：`/`、`/templates`、`/help` 在桌面与窄屏下，主视觉为贴物场景而非大片空白矢量；主色仍为蓝。  
3. 模板库：封面为场景图；选中后下方仍可见矢量字段预览。  
4. 帮助：hash 跳转与滚动仍可用。  
5. 页脚「首页」进入营销首页。  
6. `prefers-reduced-motion` 下无持续位移动画。  
7. `/app` 核心编辑/导入/打印路径冒烟未回归。
